# 段取り（Dandori）

> やりたいことを、やるべき順に。

企画・マネジメント業務の「**散らばったタスク・メモの一元化**」と「**優先度づけ**」を
ひとつの画面で行う、個人向けのタスク優先度ボードです。

抱えているタスク・メモをまとめ、「やりたいこと（目標）」に「やるべきこと（タスク）」を
紐づけ、**締切の近さ × 手軽さ** で自動採点して並べ替えます。

## 使い方

ビルド不要・依存ゼロ。`index.html` をブラウザで開くだけで使えます。

```
# どちらでもOK
open index.html                 # ファイルを直接開く
python3 -m http.server 8000     # ローカルサーバで開く → http://localhost:8000
```

データはお使いの**ブラウザ内（localStorage）にのみ**保存されます。サーバ送信はありません。

## PC起動時に自動で開く（Windows）

同梱の起動スクリプトを「スタートアップ」に登録すると、PC起動時に自動で開きます。
AIの「直接依頼」も使えるよう、ローカルサーバー（`http://localhost:8000`）で開く方式です。

1. このフォルダの **`start-dandori.vbs`** を右クリック →「**コピー**」
2. `Win + R` を押して **`shell:startup`** と入力 → Enter（スタートアップ フォルダが開く）
3. そのフォルダで右クリック →「**ショートカットの貼り付け**」

これで次回のPC起動時から、サーバーが裏で立ち上がり、ブラウザでアプリが開きます。
（`start-dandori.vbs` はサーバーを非表示で起動。ウィンドウを見たい場合は `start-dandori.bat` を使用）

- **Python が必要**です（`python -m http.server` を使用）。未導入なら [python.org](https://www.python.org/) からインストール。
- もっと手軽に済ませたいだけなら、`index.html` のショートカットをスタートアップに入れてもOK
  （`file://` で開くため「直接依頼」は使えませんが、コピペ方式や他機能は動作します）。

## スマホで使う（PWA・ホーム画面アプリ）

このアプリは **PWA** 対応です。ホーム画面に追加すると、アプリのように全画面で開けます（iOS/Android）。

スマホから開くには、まず**どこかにHTTPSで公開**する必要があります。いちばん手軽なのは GitHub Pages です。

1. GitHub のこのリポジトリ → **Settings → Pages**
2. **Source** を「Deploy from a branch」にして、このファイル一式があるブランチ＋ `/ (root)` を選択 → Save
3. 数分後に公開URL（例：`https://<ユーザー名>.github.io/web-application/`）が表示される
4. スマホでそのURLを開く →
   - **iPhone（Safari）**：共有ボタン → 「ホーム画面に追加」
   - **Android（Chrome）**：メニュー → 「アプリをインストール」/「ホーム画面に追加」

> 公開リポジトリならGitHub Pagesは無料です（非公開の場合は Netlify / Cloudflare Pages 等の無料ホスティングでも可）。
> AIの「直接依頼」はHTTPS公開なら動作します。

**注意：ログインしない場合、データは端末ごと（そのブラウザのlocalStorage）に保存されます。** 端末間で使うには、下の「アカウント連携で自動同期」を設定するか、フッターの「📤 書き出し / 📥 取り込み」で手動移行できます。

## アカウント連携で自動同期（Firebase）

Googleアカウントでログインすると、タスク・目標・メモ・設定などが**クラウド（Firebase Realtime Database）に保存され、複数端末で自動同期**されます。ログインしなくても、これまで通り端末内だけで利用できます。

> **APIキーは同期されません。** Claude / Gemini のAPIキーは引き続きその端末のローカルにのみ保存され、クラウドにも書き出しデータにも一切含まれません。

> **Realtime Database を採用**しています。Firestore は新規データベース作成に請求先（課金）の有効化を求められる場合があるため、**無料の Spark プランのまま・カード登録なしで使える** Realtime Database にしています。

同期には無料の Firebase プロジェクトが必要です（初回のみ・数分。**1つのプロジェクトを全ユーザーで共有**でき、各自は自分の Google でログインするだけ）。フッターの「☁️ ログイン / 同期…」を開くと、画面内に手順とコピペ用の設定欄があります。概要：

1. [Firebase Console](https://console.firebase.google.com/) でプロジェクトを作成
2. **Authentication → Sign-in method** で **Google** を有効化
3. **Realtime Database** を作成（**ロックモード**で開始。※ Firestore ではありません）
4. **プロジェクトの設定 → マイアプリ** でウェブアプリを追加し、表示される `firebaseConfig` の値（`databaseURL` を含む）を同期パネルの設定欄に入力
5. Realtime Database の**ルール**を「本人だけが読み書き」に設定：

   ```json
   {
     "rules": {
       "users": {
         "$uid": {
           ".read": "$uid === auth.uid",
           ".write": "$uid === auth.uid"
         }
       }
     }
   }
   ```

6.（公開URLで使う場合）Authentication →「設定」→「承認済みドメイン」に公開ドメイン（例 `lumina-debug.github.io`）を追加

設定した `firebaseConfig` はその端末のlocalStorageにのみ保存されます（クラウドには送りません）。競合は **last-write-wins**（最後に保存した内容が優先）で解決します。ログインは**ポップアップ方式**で、使えない環境（iOSのホーム画面アプリ等）では自動的に**リダイレクト方式**に切り替わります。

### 手動バックアップ / 端末間移行（JSON）

フッターの **「📤 書き出し」** で全データを JSON ファイルに保存、**「📥 取り込み」** で別端末や復元時に読み込めます（APIキーは含まれません）。同期を設定する前の保険にもなります。

## 主な機能

- **クイックメモ**：思いついたことを上部の入力欄から即メモ。あとでタスクに変換。
- **やりたいこと（目標）**：目標ごとにタスクを束ね、達成率を可視化。
- **優先度ビュー**：全タスクを優先度スコア順に自動ソート。目標で絞り込みも可能。
- **重みスライダー**：「締切重視 ↔ 手軽さ重視」をその場で調整。
- **完了管理**：チェックで完了へ。完了タブで履歴を確認。

## 優先度スコアの考え方

各タスクを 2 つの観点で 0〜100 点に採点し、重み付けして合算します（高いほど先にやるべき）。

| 観点 | 高得点になる条件 |
| --- | --- |
| **締切（緊急度）** | 締切が近い／超過しているほど高い。期限なしは低め。 |
| **手軽さ（クイックウィン）** | 作業見積が短いほど高い。すぐ終わるものを優先。 |

```
優先度 = 締切重み × 締切スコア + (1 − 締切重み) × 手軽さスコア
```

重みスライダーで「締切重み」を 0〜100% の間で調整できます（初期値 50%）。

- **締切 100%**：純粋に締切が近い順。
- **手軽さ 100%**：すぐ終わるタスクを最優先。
- **50%（既定）**：両方をバランスよく評価（例：締切間近で短い雑務がトップに来る）。
